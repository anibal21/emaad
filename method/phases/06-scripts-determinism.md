# Phase 06 — Scripts (Deterministic Workers)

## Purpose

Pull stable work out of the LLM into scripts.

## Do

1. Review domain map rows marked deterministic.  
2. Review workflows for mechanical steps (validate schema, rename, checklist compute, generate boilerplate).  
3. Create Script Cards: input, output, exit codes, who invokes, sandbox needs.  
4. Prefer boring languages already in the org; note recommendation without mandating unless user constrains.  

## Heuristic

> If two competent engineers would get the **same bytes out** given the same bytes in, it should be a script.

## Exit criteria

- Script list covers obvious deterministic work  
- Each script has an invoking agent/skill  
- Borderline LLM tasks documented with rationale
