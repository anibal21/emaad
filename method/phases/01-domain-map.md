# Phase 01 — Domain Map

## Purpose

Decompose the problem into capability domains and work types (judgment vs deterministic).

## Question set

Follow [`../questioning.md`](../questioning.md).

**Greenfield: N = 4** — announce `Fase 01 — Domain map: 4 preguntas.`

| k | Ask |
|---|-----|
| 1 | List the major capability areas (about 5–12 bullets). |
| 2 | For each area: mostly **judgment**, **procedure**, or **deterministic check**? |
| 3 | Which areas need live system access (APIs, repos, tickets, browsers)? |
| 4 | Which areas require talking directly to end users? |

**Brownfield: N = 5** — announce `Fase 01 — Domain map: 5 preguntas.`

| k | Ask |
|---|-----|
| 1–4 | Same as greenfield |
| 5 | Inventory current agents, skills, workflows, scripts, MCP servers and known pain points. |

## Produce

- Domain table: `domain | work_type | systems | user_facing | notes`  
- Brownfield inventory + pain list (if applicable)  

## Exit criteria

- Domain table reviewed by human  
- Clear candidates for scripts vs skills vs agents
